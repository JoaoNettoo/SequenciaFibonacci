# ♻️ Verificador de Sequência de Fibonacci

## ✨ Sobre o Projeto
Este projeto em **Java** verifica se um número fornecido pelo usuário pertence à **sequência de Fibonacci**.

## 👨‍💻 Como Funciona
1. O usuário digita um número.
2. O programa verifica se esse número faz parte da sequência de Fibonacci.
3. Exibe a resposta indicando se o número pertence ou não à sequência.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **Ferramentas:** Scanner para entrada do usuário

## 💪 Como Executar
1. Copie o código e salve em um arquivo `SequenciaFibonacci.java`.
2. Compile o código com o seguinte comando:
   ```sh
   javac SequenciaFibonacci.java
   ```
3. Execute o programa:
   ```sh
   java SequenciaFibonacci
   ```
4. Digite um número e descubra se ele pertence à sequência de Fibonacci!

## 🔗 Exemplo de Uso
```
Digite um número para verificar se pertence à sequência de Fibonacci: 8
O número 8 pertence à sequência de Fibonacci.
```
